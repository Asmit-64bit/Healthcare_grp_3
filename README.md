# UroScan AI

## Project Overview
UroScan AI is a browser-based academic prototype for patient record management and simulated urine testing.

## Technologies Used
- HTML5
- CSS3
- JavaScript
- jQuery
- Chart.js
- Font Awesome
- Browser localStorage and JSON

## Features
- Patient registration and search
- Patient profile management
- Simulated urine-test workflow
- Results display
- Report generation and export
- Dashboard and analytics visualizations

## Recent Changes
- Added three monthly sugar value columns to the Patients table.
- Added maximum and minimum sugar value calculations using JavaScript.
- Updated the patient table to display these values.

## How to Run
1. Clone or download the repository.
2. Open the project folder in VS Code.
3. Serve the files using a local development server, such as VS Code Live Server.
4. Open `index.html` in the browser.

## Limitations
This is an academic frontend prototype. Test results are simulated using predefined values. No trained AI diagnostic model or backend database is included.
